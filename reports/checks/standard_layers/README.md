# Standard-view verification

Run `python scripts/checks/standard_layers.py test`, then `verify`, `check` and `build` with the same script. No download is performed.

The test log records synthetic mapping, missing-column, raw-loader and cache-integrity checks. `leaks.txt` records the existing public-text leak check. The repository-wide check reports out-of-scope findings in existing files, which this task leaves unchanged. The task-path check passes. Only paths, lines and categories are saved, not matched text or allowlisted content. The decisions log checks the existing counting ledger without changing it. `sources.csv` records freshly measured sizes and SHA-256 values, compared with committed publisher checksums or the committed holding snapshot where no publisher checksum exists. `roundtrip.csv` checks one supported unit per release against its raw loader after inversion of every physical-column conversion. `charge_periods.csv` records a raw period with independently rising SOC or voltage and positive mapped charging current. The windows are fixed in the script, not selected afresh based on current polarity. This is a sign sanity check, not a layer-3 event definition or a claim that every rising voltage interval is charging.

Pilot plots show raw values after documented conversion, using DejaVu Sans. The check action regenerates them from the fixed windows without committing measurement-series copies. Schaeffer derivatives are CC BY-NC 4.0. PPL states no data license and its preview follows the maintainer's recorded permission decision. Cao derivatives follow CC BY 4.0.

`summary.csv` and `units.csv` are produced from held unit inventories and completed builds. GIS units are explicit blocks, not dropped units. Label-only snippet units are explicit empty entries. Processed values are raw after conversion, not cleaned, filtered or deduplicated. The PPL build covers the annual ESS telemetry, not the separate cell-level share. Cao uses assumed 30-second frame spacing, not measured timestamps. Cao, Zhang and EVBattery have undated partitions. PPL and Schaeffer retain wall-clock times without claiming a time zone.

Run `python scripts/checks/standard_layers.py audit` to check every supported unit's saved manifest, source content, output checksums and physical Parquet shape. Results are in `processed_audit.csv`. It also compares held processed values with their standard view in one unit per release, recorded in `processed_roundtrip.csv`. Schaeffer uses the source-order portion of its first chunk in May 2013, and PPL compares the complete annual ESS stream, including changing schema tiers and duplicated year-boundary records. Both representations convert annual inputs before concatenating them.

Source baseline: committed audits and schema notes at `d447b9eed0206f139d0a9bca6ece5fb0c8c6bc36`, not a fresh full reread of paper, supplement and author code. The maintainer approved this baseline with targeted rereads and held-data checks. Each mapping row cites its evidence, and audit-only meanings are flagged in each schema note. A new data-versus-audit disagreement requires a full reread and an entry in `docs/DECISIONS.md`. None was found by these mapping checks. Source-internal wording inconsistencies are documented there and in the notes.
